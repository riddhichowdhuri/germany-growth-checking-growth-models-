# Source Notes

## Supplied materials

1. `Germany_Growth_Development_Presentation.pdf` — the group's 23-page presentation.
2. `Germany_Growth_Development_Data.xlsx` — supplied Excel workbook containing annual variables and constructed model quantities.
3. `figures/` — extracted from the supplied `grph.zip` archive.

## Important consistency check

The presentation is explicitly a Germany project. The workbook contains Germany-like annual population observations and the project variables used for the growth models. However, several supplied figures have embedded chart titles referring to the Republic of Korea.

The figures have been preserved as supplied so that the repository does not alter the group's original outputs without authorisation.

Before final submission, regenerate or edit the affected figures so their country labels match the Germany analysis.

## Reproducibility

No original Gretl, Python or R source code was supplied with these materials. The repository therefore documents the analysis and preserves the available outputs, but does not claim complete code-level reproducibility.
